# Customer Stratification Dashboard: Interactive Mockup

This is an interactive mockup of a Power BI dashboard for a customer stratification rollout. It has three pages:

1. **Implementation**: eight implementation KPIs with a gauge, a drill-down from region to branch to person, and a monthly trend
2. **Impact**: ten financial KPIs compared with the same month last year, a breakdown by tier or region, and a 2027 vs 2026 trend
3. **Refresh and reevaluation**: the quarterly refresh calendar, its refresh steps, the branch task list, and customer follow-ups

All values are sample data. The whole mockup is the single file `index.html`, with no external dependencies.
